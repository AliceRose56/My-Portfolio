# This is the 'Film Finder' project and here's the premise:

You’ve caught up on your list of TV shows and movies and want to get recommendations for what to watch next, but aren’t sure where to look. In this project, you’ll use your knowledge of HTTP requests and asynchronous JavaScript to create a movie discovery app that will recommend random movies by genre. You’ll be able to choose from several genres, and like or dislike a movie to get another suggestion.

## What I learned from this:

1. About how to utilize APIs, read their documentation, and make projects using them
2. How to use async...await fuctions in combination with fetch requests to utilze information stored in external databases
3. The importance of protecting API keys

## Which code I worked on:
1. 'Film-Finder.js' Is where the majority of my work is. The named fuctions were already declared, but I converted them to async fuctions and wrote all of their inner code 
2. 'tmdb.js' Is not included in this repository, but it's where I declared the key funtion used in line one of 'Film-Finder.js', I used it to store and return my API key when called
3. 'Index.html' Is mostly pre-written, but I made minor tweaks to import the API key from my local file 'tmdb.js'
